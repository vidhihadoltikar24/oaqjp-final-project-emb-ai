# OpenShift CI/CD Pipeline Final Project

## Project Overview

This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions, Tekton, and Red Hat OpenShift.

The objective is to automate the application development, testing, building, and deployment process using modern DevOps tools and practices.

## Project Name

**OpenShift CI/CD Pipeline Final Project**

## Technologies Used

- GitHub
- GitHub Actions
- Tekton Pipelines
- Red Hat OpenShift
- Python
- Flake8
- Nose Testing
- YAML

## Project Objectives

1. Automate code validation using GitHub Actions.
2. Perform static code analysis using Flake8.
3. Execute unit tests using Nose.
4. Define and manage pipeline tasks using Tekton.
5. Deploy the application using OpenShift Pipelines.
6. Monitor pipeline execution and application logs.

## CI/CD Workflow

The project follows these stages:

1. Source code management using GitHub.
2. Automated linting and code quality checks.
3. Execution of unit tests.
4. Pipeline task execution using Tekton.
5. Application deployment on OpenShift.
6. Verification of deployment and application logs.

## Expected Outcome

A successfully configured CI/CD pipeline that automates application testing and deployment using GitHub Actions, Tekton, and Red Hat OpenShift.
